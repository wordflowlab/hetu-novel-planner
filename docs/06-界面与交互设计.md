# 界面与交互设计

## 1. 阅读优先

默认先展示已有规划与本次变化。作者通过Codex说明目标，回到河图按卷阅读、核对依据和提出意见；手动编辑始终可用。整书、卷、篇章分别提供适合当前范围的工作面，不要求先操作画布或生成表单。

```text
┌───────────────────────────────────────────────────────────────┐
│ 返回  小说规划  导航开关    当前方案 ▾  ＋                 导出 │
├──────────────┬────────────────────────────────────────────────┤
│ 小说资料     │ 卷概览  卷内角色  卷内势力  卷内地点  回收站   │
│ 整书规划     ├────────────────────────────────────────────────┤
│ 卷规划       │ 搜索卷                  状态   新增卷  AI目标   │
│ 篇章规划     ├──────────────┬─────────────────────────────────┤
│ 章节正文     │ 第一卷       │ ↓ 前往详细剧情          次要操作 │
│ ──────────── │ 第二卷       │ 01 卷信息   标题 副标题 状态    │
│ 实体管理     │ 第三卷       │             概要 目标 主题 统计  │
│ 伏笔与各类卡 │              │ 02 本卷规划 开局 冲突 转折      │
│ 关系图谱     │              │             首尾状态 目标预算   │
│ 正式设定     │              │ 03 详细剧情 长文 节拍 工作记录  │
│ ──────────── │              │                                 │
│ 工作记录     │              │                                 │
└──────────────┴──────────────┴─────────────────────────────────┘
```

打开插件时收起宿主顶部、左侧导航及重复标题，插件独占完整内容区。品牌栏为48px，范围页签独占下一行；搜索、状态与操作在页签下方，卷列表与分区详情共享一个工作面。插件主导航宽度随窗口为192～224px，目录为220～280px，详情使用剩余宽度。1100px以下先调整工具栏与字段列数；760px以下导航为可收起面板，目录位于正文上方。

初次打开有卷的方案时选中首个有效卷；之后恢复原节点、固定基线、恢复稿和阅读位置。卷规划显示平铺卷列表，篇章规划显示章节列表，整书规划保留完整树；不能用整书树代替卷列表。列表提供选中、状态、顺序、方向键及Home／End定位。搜索消费固定方案修订的专业查询，包含标题、副标题、目标和主题；无结果时保留当前阅读内容并提供清除筛选。

正文默认直接进入编号分区，不在卷信息上方重复大标题。卷信息依次为三列身份信息、整行概要、目标／主题／实际量；卷规划包含开局、冲突、转折、首尾变化及预算；详细剧情承载长文、节拍与真实工作记录。工作记录展示实际报告、步骤和恢复入口，不模拟生成、百分比或重连。

返回调用宿主关闭流程，先保存恢复稿，成功后恢复进入前的工作台，失败保留插件和输入；应用菜单及Alt+Left为宿主独立出口。无方案时展示具体创作目标，可由Agent准备或手动新建，不要求作者先填空卷章。

## 2. 三种工作状态

| 状态 | 默认内容 | 操作与限制 |
| --- | --- | --- |
| 阅读 | 当前范围目录、当前节点、作者主张、预算及待确认问题 | 展开、筛选、选中无需模型；历史版本明确只读 |
| 编辑 | 当前节点的内容字段，复杂字段渐进展开 | 中文输入、取消、明确保存；结构移动与归档用专用动作 |
| 比较 | 两端固定版本、节点增改及字段差异 | 可沿任意节点阅读，不只显示Agent摘要；比较不改变当前头 |

整书页面展示主题、作者主张与卷结构；卷页面展示目标及章节变化；章页面展示冲突、起止状态、转折与悬念。空字段使用简短占位，不用大批空卡片占满阅读区。

当前方案、当前修订和编辑基线分开保存。后台头发生变化时显示可查看的新版本；不替换作者正在阅读的固定内容。方案切换保留各自节点与滚动位置，不跨作品继承编辑稿。

## 3. 编辑、恢复与并发

1. 进入编辑时固定对象、revision与sha256。草稿存入宿主buffer，不能以浏览器localStorage建立第二份作品事实。
2. 中文输入法组合过程中不触发保存、结构移动或快捷键提交。编辑字段与Markdown预览共享同一草稿。
3. 切换节点、方案或作品前，提供保存、保留恢复稿或取消切换；不得静默丢弃输入。关闭重开后的恢复同时核对完整WorkRef、包摘要与视图。
4. 提交前校验完整聚合、字节预算，并将确切pending输入、原键及基线写入buffer。缓冲失败或超预算时阻止提交，输入继续可见并允许复制。
5. 成功后读取回执所指修订，再清除对应pending；不能把当前最新头当作本次结果。未知状态保留原提交，提供查询原操作，不创建新键重试。
6. 节点与方案切换先保存恢复稿；返回时读取原固定基线，异步旧回包不能覆盖新选中节点。关闭视图前通过 onBeforeClose 完成恢复稿，失败保留窗口。
7. CAS冲突提供旧基线、当前新头与草稿比较。解决冲突形成明确新请求，再使用新基线和新键；不自动覆盖。

预算按[03](03-领域模型与数据合同.md)执行。buffer可用不代表具备跨设备持久保障，也不等于已保存作品。

## 4. 意见与AI交接

意见由作者原话、当前节点ID及固定成果引用组成。可信宿主准备完整作品与授权上下文，插件不持有management_ref。交接目标可以是“调整本卷冲突”“检查两章衔接”“保留结局提出备选”等当前对象任务，不能复制统一泛化提示词。

SDK context 不包含机器 grant；可信宿主 handoff 验证并复制对象交接，onPreferences 同步外观与语言。插件不能直接向外部会话发送消息。复制成功只反馈已复制，不显示Agent已经开始。

首版不新增私有批注数据库。可保存的创作问题属于规划内容；正式批注、采纳与定稿另走宿主能力，不能由本地勾选伪造。

## 5. 视觉、布局与可访问性

遵循河图`hetu-ui-style`：使用共享Radix语义色、0.5px边界、克制的浅暗材质与可见柔和渐变；正文位于稳定纸面，不以大面积透明背景影响阅读。常规界面使用12／14／20px层级，长文按阅读需要使用18px，不为每个字段新增字号。

桌面采用目录与阅读区，窄窗将目录收起为可访问面板；信息仍可达，不通过缩小正文塞入全布局。每个状态只有一个高强调主操作，技术ID及完整摘要置于详情与复制入口，不作为标题。

主题使用宿主 preferences 初值与 onPreferences 通知；仅在跟随系统时消费系统外观。减少透明度、增强对比度设置下提供实色回退；焦点、选中和错误不能只靠颜色区分。

整书树导航遵循键盘树控件习惯，Tab进入区域、方向键展开与移动、Enter选择，焦点与选中分别表达。按钮提供可访问名称；比较视图按节点及字段读出变化，Markdown渲染禁止原始脚本、危险URL及越权远程资源。

小说资料、正式正文与正式设定使用宿主工作面入口；规划树按整书、卷、章过滤，规划卡按真实规划实体类型导航。插件导航与卷章目录可分别收起并保留状态，窄窗默认收起插件导航。范围页签显示有效卷章及归档数量；字段区按标题信息、概要及目标／统计、规划细节分行，宽窗紧凑呈现，不用大量空白占位。

## 6. 状态矩阵

| 状态 | 呈现与恢复 |
| --- | --- |
| 加载 | 保持目录与阅读边界，避免旧作品内容短暂闪现 |
| 无方案 | 具体创作目标与宿主交接入口，可手动新建 |
| 无筛选结果 | 保留方案，不误提示创建作品；可清筛选 |
| 无权／撤权 | 停止新调用，清理旧上下文展示；恢复稿按宿主隔离规则保留，不自动重新授权 |
| 包停用／缺失／升级 | 使用宿主通用读取与导出，明确专业界面不可用；新包摘要重新核权 |
| 读失败 | 显示失败及重读固定版本入口，不视为无方案 |
| 写失败 | 保留编辑与原键，区分确定失败与结果未知 |
| 结果未知 | 查询原操作，查询失败继续保留，不提供另建重复操作 |
| 版本冲突 | 三方比较与新请求，不刷新覆盖草稿 |
| 坏数据 | 列出诊断、固定修订与通用导出，不静默修复或隐藏节点 |
| 归档 | 可筛选和阅读，保留路径；恢复父级不恢复独立归档后代 |
| 超预算 | 指明超限项及实际大小，保留输入，不截断提交 |
| 来源已更新 | 保留原依据，提示可另取新版本，不自动刷新规划 |

以上状态须结合真实动作验证，视觉检查不能证明写入、授权、恢复或正文边界正确。

## 7. 完整专业工作面

主导航按任务分为整书与卷章、实体与线索、工作记录。卷章页包含概览、卷内角色／势力／地点和回收区；完整资料按卷信息、卷规划、详细剧情分区。详细剧情支持长Markdown阅读、编辑、节拍定位与固定版本比较，不放入一行备注。

实体页按角色、势力、地点、物品、规则筛选，明确规划候选与正式来源。伏笔页按未回收、已回收、归档和卷章定位；关系页提供图与表的等价视图，不要求作者连线。表与图使用同一固定故事网络，筛选不修改内容。

工作记录显示目标、真实步骤、最后回传、固定成果与恢复动作。进度未知就显示未知，不模拟百分比；停止请求与外部确认分开。已保存未接入的详情以待接入成果显示，旧规划仍可读，作者或Agent可以继续接入。

卷概览显示目标章节与目标字数、已规划章节及宿主实际正文统计。未获权、未绑定和统计失败分别表达，不能显示假0。规划状态与作者批准、正文定稿不共用颜色或标签。

“规划全书”“展开本卷”“返工此章”消费正式宿主交接桥接。正文入口、返回位置、正式来源、语言与主题同步全部属于首版必需集成；跨宿主能力按07逐项验证，证据与剩余差距统一归08。
