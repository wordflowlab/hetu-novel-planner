## 宿主合同入口

本地开发参照河图`docs/plugin/`和`packages/plugin-sdk/`，公开导航为[河图插件系列](https://github.com/limecloud/hetu/tree/main/docs/plugin)。其中20拥有现行可执行子集、21拥有动态能力发现、22拥有开发入口、23／24拥有发布及目录、26拥有Cordis采用。宿主源码URL是导航，发布验收必须固定具体提交。

仓库之间只引用各自Owner，普通文档不使用开发者本机绝对路径。当前本地核对的宿主提交和工作树边界记录于10；尚未推送的文件不宣称远端可读。
