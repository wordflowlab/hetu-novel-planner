# 实施计划与验收记录

## 1. 发布目标与当前基线

目标是[11](11-首版功能规格与发布门槛.md)规定的完整首版。工作包分步实施，完整首版须一次满足所有必需体验及安全门槛。

当前开发版包含普通TypeScript领域与应用模块、React独立工作面、锁文件、四类专业对象、21个专业动作及可执行构建包。已通过真实Core、CLI、稳定MCP和macOS Electron旅程，并安装到本机河图默认插件目录；安装启用后使用开放宿主SDK，不建立插件授权。

本轮包版本为0.1.0，包摘要为`05c6e9a51a16867a01225a1d296c692c2b4abda8b11d05fbc5c43fb0e8d6d4e8`，宿主SDK基线为公开提交a9c3551，版本0.10.0。本机桌面已覆盖安装，核对2617项应用文件／链接，插件已通过公开CLI安装及状态回读。发行材料按开发预览准备，不能据此宣称完整首版或其他平台已经验收。完整首版发布门槛仍包含Windows及第4节未验证项。
