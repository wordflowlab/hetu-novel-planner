# 首版功能规格与发布门槛

## 1. 首版定义

首版是可连续使用的小说规划工作面：整书构思→全书分卷→卷内篇章→详细剧情→实体与伏笔关联→审核返工→正式目录／正文接续。首版验收覆盖这一连续流程的全部必需能力。

本规格按创作任务定义标准插件能力。数据、操作、显示、权限和异常行为分别有合同，示例使用独立创作的演示资料。

工程实施分工作包，正式首版发布须通过本篇全部必需项。共享宿主能力需要补齐时，以跨仓依赖完成验收；不能将缺口移到“以后”再宣称首版完备。完整不等于插件复制宿主的正文、正典、授权和模型执行机制。

## 2. 功能规格

| 区域／可见元素 | 首版行为与数据 | 责任与完成证据 |
| --- | --- | --- |
| 返回书架、小说信息 | 返回河图创作库及当前小说资料，保持选择位置 | 宿主导航；完整WorkRef，不自行维护书库 |
| 卷规划、篇章规划 | 同一方案按整书／卷／章浏览，可连续下钻与返回 | 插件树、阅读页、机器节点读取 |
| 章节编辑 | 从规划节点打开或准备建立对应正式章节，比较规划与正文 | 宿主类型化导航／领域动作；正文保存另行核权 |
| 卷概览与数量 | 有序卷列表、选中态、实际有效卷数 | 插件按未归档节点计算，不手写计数 |
| 卷内角色、势力、地点 | 当前卷及子章的出场／关联对象，可切直接与包含后代 | 插件关联＋固定宿主实体来源，不能仅画空Tab |
| 回收站与数量 | 归档卷章及其附件可查看、定位、恢复，显示影响后代 | 逻辑归档；首版不提供永久删除 |
| 搜索标题、副标题、目标、主题 | 按字段和层级检索，结果定位到节点，支持清筛选 | 确定性搜索，分页／快照；非模型问答 |
| 全部状态筛选 | 规划状态筛选与归档筛选分开 | planned等是规划状态，不是作者批准／定稿 |
| 新建卷 | 手动或Agent新增，指定位置和稳定ID，可撤销编辑 | 与CLI/MCP相同动作、CAS及Schema |
| AI规划全书分卷 | 将作者意图、固定小说与已有方案交给所选Agent，回传可审阅方案 | 专用可信交接；无内置模型调用 |
| AI展开当前卷 | 仅展开所选卷的章纲／详细剧情，保护其余范围 | 固定节点、来源、预算和恢复引用 |
| 刷新 | 明确检查当前头与固定成果；有草稿时不覆盖 | 版本提示、草稿及冲突处理 |
| 卷标题、副标题 | 自由文字可读、可改，稳定ID不随标题变化 | 节点元数据 |
| 卷状态 | 待规划、规划中、已规划、待返工 | 明确人工／Agent维护；不从字段非空推导完成 |
| 卷概要 | 与详细剧情分开的一段结构摘要 | 节点详情summary |
| 本卷目标、本卷主题 | 目标与主题独立呈现，可为空并提出问题 | 详情goal／theme，全文检索可用 |
| 篇章数、字数 | 已规划章节数与宿主正文统计分别显示，含统计版本及口径 | 正文字数无权／未接入时显示不可用，不伪装0 |
| 本卷开局、主要冲突 | 开局条件与对抗机制分别记录 | opening／conflict |
| 关键转折 | 有序、可编辑、可定位的转折；保留自由文本 | turns，不强迫连线或复杂画布 |
| 起始状态、结束状态 | 明确变化与前后承接，可检查相邻卷章衔接 | start_state／end_state及检查结果 |
| 目标章节数、目标字数 | 目标、已规划量和正文实际量分别显示，可汇总差距 | target_chapters／target_words，父子预算不强制相加等于 |
| 详细剧情 | 可持续编写的Markdown正文、节拍、局部意见及固定版本比较 | 独立详情对象，不能只有短备注栏 |
| 查看生成进度、步骤 | 看真实已交接、已回传、已保存、失败或未知步骤与成果 | 工作记录引用真实回执；不模拟模型百分比 |
| 停止生成 | 向当前Agent提出停止请求并显示是否收到确认 | 请求停止≠取消成功；不擅自声称外部任务已终止 |
| 模型重连、重试次数 | 外部工具明确回传才显示；本插件不自己重连模型 | 未知结果先查原操作，避免重复付费或重复保存 |
| 伏笔 | 埋设、提示、回收节点与未解决问题，跨卷章追踪 | 规划线索与关系聚合；不另造宿主剧情正典 |
| 角色、地点、势力卡 | 计划出场、作用、状态变化、来源及必要候选草稿 | 候选与宿主正式设定分开，正式修改另走宿主方案 |
| 物品卡、设定规则卡 | 同样可引用、检索、关联到卷章和剧情 | 使用宿主实际类型；不能因上游无物品专类就伪造entity_ref |
| 关系图谱 | 人物／势力／地点／物品／规则与线索的关系；图与表两种阅读 | 固定关系及证据，Agent可操作；画布不是必经入口 |
| 创作进度、继续上次工作 | 返回确切方案／节点／工作记录，分开规划与正文进展 | 不从浏览历史推断Agent正在执行 |
| 中文／英文、主题、设置 | 复用宿主语言及外观，插件自身文案与可访问名称配套 | 宿主桥接与浅暗、窄窗、键盘测试 |

表中跨宿主功能属于首版体验的一部分，但不都由插件持久化。缺桥接先补正式宿主合同及权限验收，不用通用request或Computer Use绕过。

## 3. 完整创作旅程

1. 作者以一句梗概开始，Agent读取获权资料，整理作者主张、未定问题和整书方向；保存多份可比较方案。
2. 全书分卷，填写卷概要、目标、主题、冲突、转折、起止变化及预算；作者连续阅读并提出意见。
3. 展开某卷，建立有序章节、章纲、节拍和详细剧情；只读必要范围，不反复向模型发送全书。
4. 关联人物、势力、地点、物品和规则，梳理伏笔埋设与回收；候选设定不自动变为正式设定。
5. 检查结构、节奏预算、线索去向、角色出场和上下文矛盾，给出可定位的问题，由作者决定如何改。
6. Agent与作者都可局部调整、重排和归档；保留历史、未保存稿、原操作键及固定来源。
7. 作者要求接续正文时，Agent另准备正式卷章／大纲方案，核对映射和差异，再按独立授权执行；GUI打开实际章节。
8. 关闭桌面仍可执行机器业务；重开后读到同一固定成果，工作记录支持中断后接续。

## 4. 完整首版的门槛

必需项为：完整卷章字段与详细剧情、实体与关系／伏笔、机器操作对等、可信AI交接、真实进度与停止语义、正式章节接续、人工编辑、历史比较、归档恢复、固定导出、权限与并发恢复、浅暗窄窗与中文输入。每项必须有正向和异常证据。

不要求首版穷尽所有渲染形式、全量兼容DSH插件、跨设备实时协作或内置写作Agent。Windows与macOS分别验收；只在Mac实测不能宣称跨平台通过。

若发布包缺少本篇必需项，可以作为开发预览供明确范围测试，名称与验收记录必须说明，不能称为完整首版。
