# 局部展开

1. 固定方案和目标节点，读取祖先主张、节点详情与所需故事网络。明确仅当前节点还是包含后代。
2. 卷规划写清概要、开局、目标、主题、冲突、起止变化、转折、悬念与目标章节数；章规划补充详细剧情和节拍。
3. 实体关联记录出场作用及说明；节拍关联真实稳定的实体和线索 ID。不要把全书所有角色都算入本卷。
4. 详细剧情可以使用长篇 Markdown，不能压缩成一句备注。超过单对象预算时先调整规划粒度，不静默截断。
5. 元数据、详情保存与固定接入使用各自原键；CAS 失败保留本地内容和已保存附件，读取差异后准备新的明确操作。
6. 比较固定修订，说明变化及未触碰的范围；邀请作者对任何位置提意见。
