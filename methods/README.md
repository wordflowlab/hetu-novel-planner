# 规划方法

先通过河图发现当前包、能力摘要、确切作品授权及动作 Schema。下列方法不增加权限，也不启动模型循环；它们是包内文档，不代表已安装任何客户端 Skill。

| 目标 | 方法 |
| --- | --- |
| 建立整书结构 | [全书规划](whole-book.md) |
| 展开一卷或一章 | [局部展开](expand-scope.md) |
| 整理人物、地点、势力、规则与物品 | [故事网络](story-network.md) |
| 跟踪伏笔和关系 | [线索与关系](clues-and-relations.md) |
| 比较、返工与接续 | [返工与恢复](revision-and-recovery.md) |
| 接续正式卷章及交付 | [正式接续与交付](manuscript-and-delivery.md) |

执行入口始终为 Codex → 河图 CLI/MCP → 本插件。领域动作参数以实时发现为准；正文采纳、定稿、外发及费用另行决定。
