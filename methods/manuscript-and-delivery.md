# 正式接续与交付

1. 读取宿主实际小说目录与固定章节来源，按 ID 核对规划映射，不凭同名猜测。
2. 正式卷章、大纲和正文的调整另走河图公开领域动作及精确授权。本插件保存规划、来源和关联，不冒充正文采纳或定稿。
3. 目标字数、规划章节量与正文实际量分别展示；正文按非空白 Unicode 字符统计，没有权限或没有映射时不报假 0。
4. 导出指定方案修订的结构、详情和网络，逐段收齐 manifest，核验顺序、引用、摘要与总数。任何缺段或摘要错误都不报完整。
5. complete 导出固定创作规划，不冻结动态工作记录历史。需要工作进度时单独分页读取，每条 run 各有固定修订。
6. 机器导出返回内容。作者选择文件目标后由可信宿主写文件；不把任意路径写入权交给插件，不自动发布到外部平台。
