# 返工与恢复

1. 固定意见对应的作品、方案、节点与成果修订；旧版坐标不静默套到新版。
2. 先读原操作。成功则回读原回执所指成果；查询失败、超时或无权时保持未知。只有明确 not_found 才沿原输入和原键执行。
3. 同键不同专业输入不可重放，即使最终产生相同的底层 save。不能为了重试换键重复写入。
4. CAS 冲突分别比较编辑基线、当前版本与本地修改。互不冲突字段可合并，同字段竞写交作者选择；新基线与新键属于新的明确操作。
5. 详情已经保存而 attach 失败时保留原详情引用，重新准备确切接入，不重新生成或创建同名副本。
6. 工作记录区分 Agent 报告、可核验 Core 回执与 Agent 提供的外部回执。停止请求不等于外部已停止；未知操作先核对，成功成果不回滚。
