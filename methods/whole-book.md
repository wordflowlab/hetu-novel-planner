# 全书规划

1. 读取作品固定修订、现有方案、作者主张和已确认来源；不要因为开始规划而修改正文。
2. 将作者已经明确的主题、叙述视角、边界与保留内容记录为主张。不确定处放入待确认问题，不伪造作者决定。
3. 从整书目标、主要冲突、起止状态与关键转折推导分卷；章节数与字数是目标预算，不能冒充已经完成的正文。
4. 使用稳定 ID 建立 book → volume → chapter 结构。同名章节保留独立身份，不按标题去重。
5. 先保存结构，再按节点保存完整详情与故事网络，最后沿确切方案基线分步 attach。每步保存原键与结果引用，不宣称跨对象原子完成。
6. 分页运行结构检查，核对预算、孤点与未回收线索。创作建议供作者选择，不作为质量评分。
7. 回读本次固定成果，交接作者阅读的范围、问题及继续目标。保存规划不等于应用正式大纲。
