# 规划驱动正文接续

起草前固定作品、后续方案修订、祖先及目标节点详情、相关复盘、必要原文、故事网络、作者约束和待处理意见。逐项说明哪些是原文事实、哪些是未来建议。

宿主的固定创作任务暂不提供原生 `plugin_object` 输入类型。使用实际公开任务接口时，将所需规划摘录与确切plan/detail引用写入不可变请求说明；不要自造Core未支持的输入类型，也不要声称Core核验了规划语义。完整规划留在插件，不必每次重复传送整本书。

| 正文状态 | 任务范围 |
| --- | --- |
| 末章未完成 | 从该固定文档的确切UTF-8插入点补写，不能依据TXT字符数猜内部Markdown字节位置 |
| 本章完整、准备下一章 | 先按宿主能力准备独立正式章节或起草任务，不把规划节点当作已经存在的正文 |
| 已有参考稿需要返工 | 读同任务的稿件修订与公开意见，保存第二版并携带实际feedback_refs |
| 上游正文有新修订 | 保留旧任务；比较新事实与原基线，明确更新范围后再准备新请求 |

每版改稿仍相对任务固定原文提交patches；不得以上一版渲染全文为新授权基线。自查意见明确标为Agent自查，不伪装作者原话。保存、提交候选、作者采纳和定稿分别回读，不跳步。

回读证明至少包括：任务固定的规划摘录、原文引用及插入范围、v1、具体意见、v2与意见关联、原正文／目录／定稿状态是否保持。只有采纳真实发生后，才将采用内容补入既有剧情复盘，并继续后续规划。
