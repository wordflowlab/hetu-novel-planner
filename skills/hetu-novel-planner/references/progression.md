# 从复盘到后续规划

1. **起点核对。** 已有小说读取固定复盘、原有大纲、最新采用正文和作者目标。新书读取已有构思。缺少影响本次推进的事实时先补所需复盘；信息不足可讨论方向，不能声称无矛盾可直接写。
2. **后续总纲。** 确定后续主要冲突、人物方向、必须兑现的承诺、作者边界及结局方向。区分确定约束和备选；原文未证实的真相仍是建议。记录所依据的固定复盘引用，不仅写“基于最新规划”。
3. **卷纲。** 每卷写清起点、阶段目标、对抗、升级、关键选择、代价、卷末结果和给下一卷的义务。保留原分卷与新规划分卷的对应，跨卷重排先说明影响。
4. **章纲。** 当前卷内按实际需要展开近期章节：视角、时间地点、目标、阻碍、可获信息、选择、转折、首尾状态及结尾承接。远期可以保持粗纲，不强求全书先填满。
5. **场景节拍。** 章详情的有序 `beats` 描述入场状态、人物行动、对抗反应、转折和离场状态；需要更自由的表达时写入 `detailed_plot`。节拍是本章内容，不另造一份正式目录，也不机械限定一章一个场景。
6. **准备起草。** 核对当前章与祖先规划、必要前文、人物知情范围、线索状态和作者意见。规划后来更新不改变已经固定的写作任务；如需采用新版，应明确刷新依据和差异。

父级约束可以因下级创作发现而调整。先报告对总纲、相邻卷章及伏笔的影响，再固定新方案；未受影响节点保持。`planned`只是维护的规划状态，不表示正文已完成或作者已批准。

复盘、规划、参考稿和采用正文构成循环：参考稿返工先沿同一任务；作者采用后，增量复盘本次正文，再更新未写范围的规划。未采用候选不进入已发生剧情。
